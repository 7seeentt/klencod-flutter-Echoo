# ECHO FX

تطبيق صدى مباشر للصوت باستخدام المايك.

## الميزات

- صدى صوت مباشر
- التحكم بمستوى الصدى من 0 إلى 100
- تشغيل وإيقاف
- واجهة عربية
- بناء APK باستخدام GitHub Actions

## البناء

من GitHub:

1. افتح تبويب Actions.
2. اختر Build Android APK.
3. اضغط Run workflow.
4. انتظر اكتمال البناء.
5. افتح نتيجة البناء.
6. حمّل Artifact باسم ECHO-FX-APK.

## ملاحظة

يفضل استخدام سماعات عند تشغيل تأثير الصدى.
